# Recto (iOS)

SwiftUI notes + Task Center app — **free**, no subscription. Open **[Recto/Recto.xcodeproj](Recto/Recto.xcodeproj)** in Xcode 15+ (iOS 17). See [Recto/README.md](Recto/README.md) for the feature list and run steps.

Data stays on this device. This Linux environment cannot compile an iOS target — use a Mac.
